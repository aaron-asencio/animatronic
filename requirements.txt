# PINNED TO 1.x (NOT 2.x) ON PURPOSE: the apt `python3-picamera2` stack and its
# C deps (e.g. simplejpeg) are compiled against the system numpy 1.24 ABI, and
# Camera_Service imports picamera2 from system site-packages (the venv is built
# with --system-site-packages). A venv numpy 2.x triggers
# "numpy.dtype size changed" ABI errors inside picamera2. No project code uses
# numpy-2-only APIs, so 1.x is sufficient everywhere. Keep <2 until the Pi OS
# image ships a picamera2/simplejpeg built against numpy 2.
numpy>=1.24,<2
